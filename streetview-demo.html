Walayar Hospital 360° Walkthrough

Interactive property walkthrough powered by Google Maps Street View. Explore the entrance, pharmacy, and hospital campus with full Street View navigation chevrons.

🛠️ Setup & Environment Configuration

  1. Enable APIs in Google Cloud Console: Enable Maps JavaScript API and Maps Embed API.
  2. API Key Variable: Set window.GOOGLE_MAPS_API_KEY = "YOUR_KEY" or VITE_GOOGLE_MAPS_API_KEY.
  3. Key Restrictions: Restrict by HTTP referrers (e.g. https://yourdomain.com/*) to prevent unauthorized usage.
  4. Fallback Behavior: When no API key is provided, the component displays an interactive launch card with a direct deep link into Google Maps.
